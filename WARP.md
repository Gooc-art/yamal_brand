# WARP

## Web Service Focus

Активный продукт в этом репозитории: `yamal_catalog_site_php`.

Текущий контур:
- PHP + SQLite каталог бренд-материалов
- главное меню по реальным разделам каталога
- поиск, deep links, карточка файла, предпросмотр и скачивание
- grounded-помощник по каталогу и брендбуку
- `Лаборатория решений` для типовых носителей

## Лаборатория решений

Сейчас поддерживаются:
- визитка
- табличка
- презентация
- сертификат
- бейдж
- фирменный бланк
- пост для соцсетей
- роллап / стенд

Формат работы:
- пользователь заполняет поля
- сайт собирает SVG/HTML/JSON handoff-пакет
- рядом подбираются реальные разделы и реальные файлы каталога

Границы текущей версии:
- без свободного редактирования макета
- без хранения пользовательских проектов
- без настоящего `PPTX`-рендера
