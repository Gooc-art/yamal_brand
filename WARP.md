# WARP

## Web Service Focus

Активный продукт в этом репозитории: `yamal_catalog_site_php`.

Текущий контур:
- PHP + SQLite каталог бренд-материалов
- главное меню по реальным разделам каталога
- поиск, deep links, карточка файла, предпросмотр и скачивание
- grounded-помощник по каталогу и брендбуку
- `Лаборатория решений` для типовых носителей

## Лаборатория решений

Сейчас поддерживаются:
- визитка
- табличка
- презентация
- сертификат
- бейдж
- фирменный бланк
- пост для соцсетей
- роллап / стенд

Формат работы:
- пользователь заполняет поля
- поля сгруппированы по смыслу, а у лаборатории есть фильтры по типу носителя
- первый заход в конструктор использует облегчённый draft без тяжёлого file-search; полный подбор файлов включается уже на сборке
- открытие и сборка конструктора сами раскрывают workspace и в случае ошибки показывают retry-state, а не молчаливую пустоту
- сайт собирает SVG/HTML/JSON handoff-пакет
- `Табличка` собирается как фиксированный кабинетный/навигационный/зональный шаблон
- `Презентация` отдает cover + brief со сценарием, тезисом и структурой слайдов
- для всех решений есть общий grounded-слой оформления: цветовые версии `CMYK / Color / Black / White`, переключение `логотип / фирменный знак` и набор фоновых режимов на базе реального знака и каталожной структуры брендбука
- у конструктора есть отдельная grounded-палитра фона: `paper / sand / accent / teal / gold / ink`; на плотных тонах логотип и знак автоматически могут уходить в белую контрастную версию
- композиция шаблона тоже зависит от выбранных элементов: `фирменный знак` и `логотип с надписью` больше не обязаны делить одну и ту же раскладку
- в интерфейсе эти style-режимы собраны в карточки выбора с короткими пояснениями, а не в простые select; смена режима сразу пересобирает превью
- типографика этих карточек выбора тоже держится консервативно: длинные названия и пояснения должны оставаться внутри плашек без наложения и рваного переноса, а палитра должна обходиться без тесного текста прямо внутри swatch
- поверх полей есть быстрые grounded-пресеты по сценариям носителя: они одной кнопкой переключают рабочий режим без ручного клика по каждому параметру
- внутри конструктора handoff теперь делится на два сценария:
  `На согласование` и `Подрядчику`, чтобы visual/brief и production-исходники шли отдельными пакетами
- рядом с превью должен быть компактный индикатор заполнения шаблона, а не отдельный длинный summary-блок под формой
- нижняя поддержка конструктора должна оставаться компактной: в draft достаточно одного короткого grounded-блока с разделами и советом, а после сборки каталоговая часть должна жить уже внутри handoff
- кегль в SVG-полях подстраивается под доступный блок, чтобы длинные подписи и заголовки оставались в рамках макета
- для всех шаблонов используется общий fitter с безопасными внутренними полями: он старается сохранить полный текст без лишних троеточий и переносит дефисные/служебные токены более естественно
- handoff-пакет тоже держит это оформление: HTML/JSON brief фиксирует выбранный цветовой вариант, логотип и элементы фона
- preview-контура и кнопочные панели конструктора тоже адаптируются под тип носителя, чтобы wide и tall шаблоны не ломали UI
- карточки и фильтры самой лаборатории держатся минимальными: без format-pills и без числовых бейджей внутри кнопок
- на карточках решений используются короткие summary, а не длинные абзацы, чтобы витрина читалась как деловой каталог
- рядом подбираются реальные разделы и реальные файлы каталога

Границы текущей версии:
- без свободного редактирования макета
- без хранения пользовательских проектов
- без настоящего `PPTX`-рендера
