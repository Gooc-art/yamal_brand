# Предложенная полная структура кнопок (Макеты1)

## Уровень 1
- Логотип
- Фирменный знак
- Детский логотип
- Логотипы городов
- Паттерны
- Брендбук ЯМАЛ 100
- Брендбук ЯМАЛ Мастер бренд
- Брендбук Салехард
- Брендбук Новый Уренгой
- Брендбук Ноябрьск
- Иллюстрации мастер-бренда SVG-элементы
- Шрифт
- Каталог сувенирной продукции

## Уровень 2 и глубже

- После нажатия на кнопку верхнего раздела бот показывает вложенные папки и файлы как кнопки.
- Для важных разделов применяются короткие человекочитаемые названия вместо сырых имен папок.
- Для городских брендбуков вынесены отдельные кнопки верхнего уровня.
- Навигация идет по реальной структуре каталога, без ручного дублирования каждого уровня.
- Для возврата доступны кнопки `Назад` и `Меню`.

## Спец-структура кнопок

- `Логотип`: `Базовый логотип`, `С охранным полем`, `Угловые логотипы`, `Ямал 95`
- `Фирменный знак`: `Знак`, `Знак + ЯМАЛ`
- `Логотипы городов`: `Новый Уренгой`, `Ноябрьск`, `Салехард`
- `Паттерны`: `Новый Уренгой`, `Ноябрьск`, `Салехард`
- `Каталог сувенирной продукции`: `Сувениры`, `Канцелярия`, `Полиграфия и навигация`, `Диджитал`, `Шрифты`
- технические названия вида `1. CMYK для печати` и `1-1 детские футболки` сокращаются до понятных кнопок
- у брендбуков прямые PDF-файлы показываются раньше папки `Файлы и исходники`

## Почему так
- Пользователь сразу видит все основные папки верхнего уровня.
- Не нужно догадываться, в каком «сборном» разделе лежит нужный файл.
- Дальше бот раскрывает структуру каталога как есть, кнопками.

## Статус
- Эта структура реализована в текущем главном меню бота.
- Все верхние папки вынесены в отдельные кнопки.
- Вложенные папки и файлы открываются по иерархии каталога.
- Для ключевых разделов второй уровень уже нормализован под пользователя.
